## 1. What this project is

A personal NVDA equity-DD workspace. YAML is the source of truth; Python
build scripts regenerate `workbooks/NVDA_Financials.xlsx` and
`workbooks/NVDA_Guidance_Tracker.xlsx`. `workbooks/NVDA_Projections.xlsx` is
hand-built — scripts only write into named input cells. Research docs are
summarized in `research/` with a `## Key Implications` section at the end of
every file. Every forecast change gets a `views/changelog.md` entry.

Full rules and invariants are in `CLAUDE.md`. **Do not re-derive them.**

## 5. Known issues / gotchas

- **`pypdf` import error on first run** (`ModuleNotFoundError: _cffi_backend`):
  seen previously. If it recurs, try `pip install -r requirements.txt`; if
  still broken, `pip install pypdf --force-reinstall`. As a fallback, use
  `pdftotext` (poppler-utils) if installed, or ask the user to paste the
  table text.
- **`openpyxl`** — use explicit `Font(...)` constructors, not `.font.copy()`
  (which is deprecated in newer versions).
- **`yaml.safe_dump` strips comments.** If you need to edit an existing
  YAML while preserving its header comments (like `data/assumptions/base.yaml`),
  write line-wise edits via the `Edit` tool — don't round-trip through
  `yaml.safe_load` / `yaml.safe_dump`.
- **Named ranges in `NVDA_Projections.xlsx`** — 183 `nv.*` ranges already
  defined. `write_projection_inputs.py` writes to them and skips null
  values. Don't touch this workbook's structure; it's hand-built.
